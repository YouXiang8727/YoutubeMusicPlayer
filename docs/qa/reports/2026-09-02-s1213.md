## 逐項煙霧結果

### Step 1 安裝與啟動 — **PASS**

- 安裝 Success；啟動後 app 進程存活，無 ActivityManager/AndroidRuntime FATAL、無 ANR（logcat 檢查）。
- 注意：logcat 有系統層雜訊（`com.google.android.bluetooth` SIGABRT、`uiautomator` stub 衝突），皆非本 app、與本功能無關。

### Step 2 榜單載入（★未知數 1）— **FAIL**

**現象（決定性失敗）**：

- 「台灣熱門音樂」**標題存在**（rail 標題有顯示，coords 508,862）。
- rail 內**無任何歌曲項目**（無名次、無縮圖、無歌名、無歌手）。
- rail 畫面中央偏下顯示**「重試」按鈕**（672,1244），但「查看完整榜單」按鈕（1132,862）仍存在。
- 點「查看完整榜單」進入完整榜單畫面 → 畫面僅「返回熱門列表」（120,862）+「重試」（672,1244），**無列表內容**（預期 50 筆名次式樣列表）。
- 點「重試」後等待 20 秒 → 仍停在「重試」狀態，無任何歌曲列表出現（恢復無效）。

**網路診斷（確認非網路問題）**：

- `adb shell ping -c 2 charts.youtube.com` → PING `youtube-ui.l.google.com (108.177.125.190)` 通，0% loss（108ms）。
- `adb shell ping -c 2 www.google.com` → 通（504ms）。
- 設備 WiFi 狀態：`NetworkState(isRestricted=false, isOnline=true, isWifiConnected=true)`（logcat NearbySharing）。
- **app 對 YouTube 搜尋 API 正常通**（見 Step 7）——證明 app HTTP 層與 YouTube 主 client 功能正常。

**結論（★未知數 1 重點回報）**：

> **TW TopSongs 榜單資料鏈載入失敗**。既然設備可解析並連通 charts.youtube.com（ping 通），且 app 對其他 YouTube client 請求正常，此失敗指向 **榜單端點專屬問題**（YT 對 charts 端點回傳非預期結構／geo/bot 阻擋／端點失效）。此為本功能最大風險，且已於實機確認為真實失敗（非測試環境誤報）。

> 因榜單無內容，「切飛行模式再開實測 TrendingRetry 顯示錯誤與恢復」之切換測試無法完整進行；已記錄「重試」無效復現一次（重試後仍失敗）。

### Step 3 完整榜單 — **受限**（受 Step 2 失敗影響）

- 點「查看完整榜單」能進入完整榜單畫面，但顯示失敗狀態（「重試」+無內容），**實際筆數無法記錄**（預期 50）。
- 畫面元素（MCP WaitForElement 確認）：「返回熱門列表」（120,862）+「重試」（672,1244），無歌曲。
- 判定：無法驗證「完整 50 筆列表（名次式樣）」。

### Step 4 起播（★未知數 2）— **受限**（受 Step 2 失敗影響）

- 榜單無歌曲可點，無法從榜單中段（第 3~5 首）起播，無法驗證「以整份榜單為暫時性佇列」之行為。
- **側面驗證**：我已透過一般搜尋播放驗證 `encryptedVideoId` 起播鏈（搜尋結果亦使用 encryptedVideoId）——成功進入 PLAYING（見下節）。但**榜單起播專屬路徑**（以榜單為佇列）仍受限。
- 判定：無法驗證「下一首/上一首/整份榜單連續切歌」。

### 播放模式 / 通知列（Step 5、6）— **受限**

- 因無榜單佇列可播放，循環全部／循環單曲／隨機切換、通知列 MediaSession 的曲目操作，均無法以榜單佇列驗證。
- **側面觀察**：搜尋影片播放時，MediaSession 已註冊（`MediaSessionService: addSession ... androidx.media3.session.id./88`），含自訂 actions：上一首、下一首、播放/暫停、循環模式（logcat 確認）。

### Step 7 邊界（搜尋隱藏榜單／清除復現） — **PASS**（榜單隱藏與復現正確）

- 空狀態下輸入搜尋「lofi」並執行 → 「台灣熱門音樂」**隱藏**（`WaitForElement 台灣熱門音樂` → not found），搜尋結果列表正常出現（app 對 YouTube 搜尋 API 通，與先前「test」搜尋一致）。
- 清除搜尋 → 「台灣熱門音樂」**復現**（`WaitForElement` → found）。空狀態榜單區塊回歸。
- 判定：searched=true 隱藏榜單與清除回歸邏輯正確。**但注意：復現的榜單仍是載入失敗狀態**（承接 Step 2）。

### Step 8 logcat 全程監控 — **PASS**

- 全程 logcat 檢查：**無** `FATAL EXCEPTION`、**無** `ANR in`、**無** `IllegalArgumentException: Key ... was already used`（LazyColumn duplicate key）、**無**本 app（com.youxiang8727）AndroidRuntime error。
- 系統有無關之 bluetooth SIGABRT 雜訊（見 Step 1 備註）。
